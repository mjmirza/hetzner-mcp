## 2026-06-07 - Path Traversal via Percent-Encoding and Backslashes in Node URL Parsing
**Vulnerability:** In Node's WHATWG URL implementation, backslashes `\` are normalized to `/` and percent-encoded dots (such as `%2e%2e`) are resolved to dot-dot segments during URL parsing. If path validation occurs only on the raw string before URL construction and parsing without first decoding, callers can bypass path traversal safeguards.
**Learning:** Checking for literal substrings like `".."` or `"\` on raw inputs is insufficient when the target parser decodes or normalizes characters (like backslashes or percent encodings) as part of its URL resolving process. Path validation must always decode percent encoding using `decodeURIComponent` first, and then explicitly check both the raw and decoded string for path traversal sequences, backslashes, and control characters.
**Prevention:** Always use a robust, multi-phase sanitization helper (`normalizePath`) that decodes paths via `decodeURIComponent` first, and rejects any malformed sequences, dot-dots, backslashes, or control characters in both the decoded and original representations before building URL objects.
