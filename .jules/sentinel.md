## 2026-07-19 - Path Traversal via URL normalization of backslashes and percent-encoded dot-dots
**Vulnerability:** The `normalizePath` function only checked for `..` directly in the raw path string. An attacker could bypass this check by using percent-encoded dot-dots (like `%2e%2e`) or backslashes (like `\`), which Node's WHATWG URL implementation normalizes and resolves to path traversal segments during parsing (e.g. `new URL('https://api.hetzner.cloud/v1' + '/servers/%2e%2e/%2e%2e/admin')` becomes `https://api.hetzner.cloud/admin`), potentially leading to SSRF or unauthorized access to other endpoints.
**Learning:** In standard-compliant URL parsers like WHATWG, backslashes are normalized to forward slashes and percent-encoded dot-dots are decoded and resolved into relative path segments. Checking raw inputs before URL-decoding is insufficient for security validation.
**Prevention:** Always URL-decode the path via `decodeURIComponent` before checking for forbidden sequences like `..` and `\`.
