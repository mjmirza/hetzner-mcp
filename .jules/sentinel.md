## 2026-06-07 - Path Traversal and SSRF via WHATWG URL Normalization Bypass
**Vulnerability:** In Node's WHATWG URL implementation, backslashes (`\`) are normalized to forward slashes (`/`) and percent-encoded dots (like `%2e%2e`) are resolved to dot-dot (`..`) segments during URL parsing. This bypasses simple substring checks (such as checking if a path includes `..`) and can lead to path traversal and Server-Side Request Forgery (SSRF) vulnerabilities.
**Learning:** Simply checking raw path input for `..` or control characters is insufficient if the path is later used to construct a `URL` object in Node.js. Input paths must be decoded with `decodeURIComponent` first, and checked explicitly for both `..` and `\` to prevent bypasses.
**Prevention:** Always decode any relative path using `decodeURIComponent` and perform checks for path traversal sequences (`..`), backslashes (`\`), control characters, and malformed percent encodings on the decoded string before using it to construct a WHATWG `URL`.
