## 2026-07-26 - WHATWG URL Path Traversal Bypass via Percent Encoding and Backslash normalization
**Vulnerability:** Node's WHATWG URL implementation normalizes backslashes `\` to `/` and resolves percent-encoded dots (such as `%2e%2e`) to dot-dot (`..`) segments during URL parsing. If path-based SSRF/traversal validation (like `normalizePath`) does not decode the path using `decodeURIComponent` and check for both `..` and `\`, an attacker can bypass traversal checks (e.g. `/servers/%2e%2e/admin` or `/servers/..\\admin`) and still traverse the path during final URL resolution.
**Learning:** Checking for literal `".."` or `"\\"` in a raw URL path is insufficient. Because URL parsers often decode percent encodings (such as `%2e` for dot) and normalize backslashes before or during path segment resolution, validations must inspect the fully decoded and normalized representation.
**Prevention:** Always decode URL paths using `decodeURIComponent` (or equivalent) before performing path traversal and boundary validation. Reject any input that contains `..` or `\` in either its raw or decoded forms, and reject malformed percent-encoded sequences to prevent bypasses.
