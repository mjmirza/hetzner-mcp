## 2025-02-12 - Path Traversal & SSRF Path Normalization Vulnerability in normalizePath
**Vulnerability:** In Node's WHATWG URL implementation, backslashes (`\`) are normalized to forward slashes (`/`) and percent-encoded dot segments (like `%2e%2e`) are resolved to dot-dot (`..`) segments during URL parsing. If the server does not decode the path using `decodeURIComponent` and explicitly reject `\` and `%2e%2e` sequences before passing it to `new URL()`, attackers can perform path traversal or Server-Side Request Forgery (SSRF).
**Learning:** Simple string checks like `.includes("..")` or control character checks can be bypassed by using alternative representations like `%2e%2e` or backslashes `\`. URL parsers may handle/normalize these characters differently than basic string matches expect, leading to security check bypasses.
**Prevention:** Always decode user-supplied paths via `decodeURIComponent` and check for both `..` and `\` in both raw and decoded strings, as well as checking for control characters and malformed percent encodings, before performing any path-based or URL operations.
