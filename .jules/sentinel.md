## 2026-08-02 - Path Traversal & SSRF Bypass via Normalized/Percent-Encoded Path in normalizePath
**Vulnerability:** The relative API path validation `normalizePath` previously only checked for the raw substring `..` and raw control characters, but did not check for backslashes `\` or handle percent-encoded characters (like `%2e%2e` or `%00`). Because Node's WHATWG `URL` implementation normalizes backslashes `\` to slashes `/` and decodes percent-encoded dots to dot-dot segments during URL parsing, a user could bypass path validation and perform arbitrary path traversal or Server-Side Request Forgery (SSRF) using inputs like `/servers/..\\..\\admin` or `/servers/%2e%2e/%2e%2e/admin`.
**Learning:** During WHATWG URL parsing, Node's URL parser performs characters normalization (such as normalizing `\` to `/`) and resolves percent-encoded characters before resolving path segments. Consequently, raw substring checks on input strings before URL parsing are insufficient.
**Prevention:** Always decode user-supplied paths via `decodeURIComponent` prior to validation, and explicitly reject both `..` and `\` substrings, along with malformed percent encoding and control characters in both raw and decoded forms, before the path is appended to a base URL or passed to a URL parser.
