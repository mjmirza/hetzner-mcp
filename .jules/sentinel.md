## 2026-06-07 - WHATWG URL Path Traversal Bypass via Percent Encoding and Backslashes
**Vulnerability:** In Node's WHATWG URL implementation, backslashes (`\`) are normalized to forward slashes (`/`), and percent-encoded dot segments (such as `%2e%2e` and `%2E%2E`) are resolved to dot-dot (`..`) segments during URL parsing. If the path validation relies purely on raw string matching for `..` or does not explicitly handle backslashes, a client can bypass path traversal and SSRF checks by sending paths like `/servers/%2e%2e/admin` or `/servers/..\\admin`.
**Learning:** Raw relative path checking without decoding percent-encoded sequences or normalizing backslashes allows malicious inputs to pass validation while resolving to traversed endpoints during actual HTTP request construction.
**Prevention:** Always decode paths using `decodeURIComponent` (safely handling `URIError` for malformed percent-encoding) and explicitly check both the raw and decoded paths for both `..` and `\` before passing them to URL constructors or HTTP clients.
