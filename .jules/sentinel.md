## 2025-02-13 - Path Traversal & SSRF bypass in normalizePath
**Vulnerability:** Path validation only checked for raw ".." and did not handle percent-encoding (like "%2e%2e"), backslashes, or malformed percent-encoding. Under Node's WHATWG URL implementation, backslashes are normalized to slashes and percent-encoded dots resolve to dot-dot segments during parsing, allowing attackers to bypass the ".." filter and perform path traversal or Server-Side Request Forgery (SSRF).
**Learning:** Checking for substrings in raw input before decoding percent-encoding leaves a major gap, as URI parser implementations decode percent-encoded values and normalize separators (like backslashes to slashes) afterwards.
**Prevention:** Always decode any user-supplied path using `decodeURIComponent` first, explicitly handle any potential malformed URI errors, and then validate the decoded path for both ".." and "\" segments to guarantee that traversal and SSRF bypasses are safely prevented.
