## 2026-08-10 - Path Traversal & SSRF Bypass via Percent-Encoded Dot-Dot & Backslash
**Vulnerability:** Under Node's WHATWG URL implementation, backslashes (`\`) are normalized to forward slashes (`/`), and percent-encoded dot-dot segments (e.g. `%2e%2e`) are resolved to actual dot-dot segments (`..`) during URL parsing. Because the original input path sanitization in `normalizePath` only performed a raw check for `..` before decoding percent encoding and without blocking backslashes, path traversal sequences like `/servers/%2e%2e/admin` or `/servers/..\\admin` successfully bypassed the check and were normalized by `new URL()` into `/admin`.
**Learning:** Checking for path traversal sequences like `..` on raw, undecoded input string paths is insufficient and easily bypassed. Furthermore, differences in URL parser normalization (such as backslash/forward slash normalization in WHATWG URL standard) can lead to unintended path resolution.
**Prevention:** Always decode paths using `decodeURIComponent` first, handle malformed percent-encoding exceptions, and perform both `..` and `\` safety checks on the fully decoded path representation before constructing URLs.
