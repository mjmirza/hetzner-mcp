## 2026-06-07 - Path Traversal & SSRF Mitigation via Decoded Path Validation
**Vulnerability:** Node's WHATWG URL implementation normalizes backslashes `\` to forward slashes `/` and resolves percent-encoded dots (e.g. `%2e%2e`) to dot-dot path segments during parsing. If raw paths are not properly decoded before validation, attackers can bypass path traversal and SSRF checks using characters like `%2e%2e` or `\`.
**Learning:** Checking path validation only on raw URL/path strings is insufficient because URL parsers, HTTP libraries, and target APIs often automatically normalize backslashes and decode/resolve percent-encoded characters, potentially leading to unauthorized directory traversal or SSRF.
**Prevention:** Always decode user-supplied paths via `decodeURIComponent` first, catch any malformed encoding errors, and explicitly check both raw and decoded inputs for path traversal sequence `..`, backslashes `\`, control characters, and protocol-relative/absolute URLs before passing them to the URL constructor or downstream systems.
