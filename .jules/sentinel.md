## 2026-07-28 - WHATWG URL Path Traversal and SSRF via Percent-Encoded Dots and Backslashes
**Vulnerability:** Under Node's WHATWG URL implementation, backslashes (`\`) are normalized to forward slashes (`/`), and percent-encoded dots (such as `%2e%2e` / `%2E%2E`) are resolved to dot-dot (`..`) segments during URL parsing. A simple check for `includes("..")` on a raw input path can be easily bypassed by using percent-encoded dots or backslashes, resulting in severe path traversal or SSRF vulnerabilities if the resulting URL is fetched.
**Learning:** Checking raw input paths before they are parsed by standard URL or HTTP libraries is insufficient because those libraries normalize, parse, and resolve percent encodings and directory separators internally.
**Prevention:** Always decode the path using `decodeURIComponent` (handling any potential decoding errors) and explicitly validate that the fully-decoded path does not contain path traversal indicators like `..` or backslashes `\` before passing the path to the URL parser or network clients.
